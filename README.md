# YUGA — The Universe of Design

A responsive, single-page landing page for YUGA, built with a premium black-and-white editorial aesthetic and deep cobalt blue accent (#2C3480).

## Features
- Responsive desktop, tablet, and mobile layouts
- Editorial typography (Playfair Display + DM Sans)
- Four design worlds: Fashion, Architecture, Accessories, Interiors
- Anchor navigation and responsive image cards
- Lightweight static HTML/CSS; no build step or framework required

## Run locally
Open `index.html` in your browser.

## Deploy with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Wait for GitHub Pages to publish the site.

Images and fonts are loaded from external providers (Unsplash and Google Fonts).
